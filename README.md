258 tests in total

## How to run tests in Eclipse:

1. Import the project

2. Right-click "src/test/java" -> run as -> JUnit Test
   
3. All 258 tests should pass

## How to get coverage report:

1. Right-click "src/test/java" -> Coverage As -> JUnit Test
